# AI Context - Molitor Project

> Ezt a fájlt minden AI asszisztensnek el kell olvasnia, mielőtt kódot generál vagy módosít.

## ⚡ Gyors Referencia

### Projekt Típus
**Moduláris Laravel + Vue 3 Monorepo**

### Kritikus Szabályok

#### 🔴 Backend (Laravel/PHP):
```
CSAK ITT: /packages/
```
- Controllers → `/packages/[name]/src/Controllers/`
- Models → `/packages/[name]/src/Models/`
- Services → `/packages/[name]/src/Services/`
- NE használd: `/app/`, `/app/Http/Controllers/`, stb.

#### 🔵 Frontend (Vue/TypeScript):
```
CSAK ITT: /resources/js/packages/
```
- Components → `/resources/js/packages/[name]/components/`
- Views → `/resources/js/packages/[name]/views/`
- Services → `/resources/js/packages/[name]/services/`
- Types → `/resources/js/packages/[name]/types/`
- NE használd: `/resources/js/components/`, `/app/vue/`, stb.

## 📦 Meglévő Csomagok

### Backend (`/packages/`)
- `user` - Felhasználók, auth
- `cms` - Content management
- `media` - Média kezelés
- `admin` - Admin funkciók
- `article-parser` - Article parsing
- `article-scraper` - Web scraping
- `html-parser` - HTML parsing
- `rss-watcher` - RSS monitoring
- `theme` - Theme settings
- `setting` - Settings
- `language` - Nyelvek

### Frontend (`/resources/js/packages/`)
- `vue-user` - User UI, auth views
- `vue-admin` - Admin UI, shared components
- `vue-cms` - CMS frontend

## 🎯 Példák

### ✅ Helyes
```
Backend:  /packages/user/src/Controllers/AuthController.php
Frontend: /resources/js/packages/vue-user/views/auth/Login.vue
Service:  /resources/js/packages/vue-user/services/authService.ts
Type:     /resources/js/packages/vue-user/types/user.ts
```

### ❌ Helytelen
```
Backend:  /app/Http/Controllers/AuthController.php
Frontend: /resources/js/components/Login.vue
Service:  /resources/js/services/authService.ts
Type:     /resources/js/types/user.ts
```

## 🛠️ Tech Stack
- **Backend:** Laravel 12, PHP 8.2+, Sanctum Auth
- **Frontend:** Vue 3, TypeScript, Vite, Tailwind CSS 4
- **DB:** SQLite (dev), MySQL (prod)
- **Container:** Docker (Laravel Sail)
